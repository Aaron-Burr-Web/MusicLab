音程与和弦（三）：和弦

把音程叠起来

三个或更多音同时发声，音程关系便组织成和弦。

先掌握三和弦，再扩展到七和弦；这是最有效的和声入门路径。

01

四种 C 三和弦

三和弦由根音、三度音和五度音组成。大、小、增、减的差别来自两段三度的排列。

C 大三和弦根音 C、三度音 E、五度音 G。听起来通常明亮、稳定。
02

读懂和弦标记

根音加类型即可快速标记：C 是 C 大三和弦，Cm 是小三和弦，Caug 是增三和弦，Cdim 是减三和弦。用同一套规则可以推断其他根音。

C majorCm minorCaug augmentedCdim diminished
03

从三和弦到七和弦

在三和弦上再叠加一次音程，就得到七和弦。它的色彩和导向性更丰富，常会强调七音和三音；必要时可省略五音，保持声音清晰。

标记构成听感
Cmaj7C E G B明亮、延展
C7C E G B♭有解决倾向
Cm7C E♭ G B♭柔和、内敛
Cm7♭5C E♭ G♭ B♭紧张、不稳定

掌握三和弦和七和弦已足以应对多数入门创作。九、十一、十三和弦会在七和弦上加入扩展音，也常省略未被强调的音。

04

和弦听辨

通过听辨巩固和弦性质。这个练习更考验基础听觉，适合反复完成。

在学习了和弦相关知识后，你就可以更好地实践DAW创作了。
