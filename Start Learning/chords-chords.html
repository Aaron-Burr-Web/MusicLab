音程与和弦（三）：和弦

和弦

和弦是三个或更多音同时发声时形成的组合，常见类型包括三和弦、七和弦和九和弦，通俗地说，和弦是多个音程的叠加，并且它们的听感与音程的听感几乎相同。例如大三和弦通常给人明亮、稳定的感觉，小三和弦更常带来忧郁或柔和的色彩，这与音程是一致的。

从初学者角度看，先掌握三和弦是最有效的入门方法。你可以从 C 大三和弦等简单结构开始，逐步感受稳定与张力的变化，再尝试把它们加入旋律中。三和弦由三个音组成，他们分别为根音、三度音和五度音，而和弦多分为大、小、增、减，下面试听块展示了四种 C 三和弦的听感。

将三和弦拆解为两个音程关系，再次参照钢琴键盘你会发现，大三和弦是大三度+小三度，小三和弦是小三度+大三度，增三和弦是大三度+大三度，减三和弦是小三度+小三度。他们分别对应major、minor、augmented和diminished。根据它们的类型，结合根音的音名，我们拥有了简化标记。

例如，C 大三和弦可以简化标记为 C，C 小三和弦为 Cm，C 增三和弦为 Caug，C 减三和弦为 Cdim。通过这种方式，我们可以快速识别和弦类型，而无需每次都分析其内部音程结构。

类似的你可以推断出所有的三和弦和他们的对应关系。

在三和弦的基础上，再做一次音程叠加，可以找出对应的七和弦，下方的表格展示了常见的七和弦及其构成音程关系。七和弦有着更丰富的内涵和表现力，能够为音乐增添更多的色彩和情感层次，由于种类也更加繁多，你需要更长的时间去记忆。

但是七和弦并非都是四个音，它一般强调七音，次强调三音，而根音和五音的存在感相对较弱，但根音保证了和弦的基础音程，所以有的时候，我们可以去掉其中的五音，获得三个音的七和弦，这可以避免因过多音的叠加而造成声音的混杂，这使得七和弦在和声中具有更强的导向性和张力。

对于初学者来说，掌握三和弦和七和弦已经足够应对大部分的音乐创作和演奏需求。更多音的扩展和弦，这里不做详细介绍，与七和弦类似，他们在七和弦的基础上加入扩展音，但一般只采取自然大调音阶上的音程，例如大九度、纯十一度、大十三度等，且一般与七和弦类似，会省略掉未被强调的音，从而保持和弦的清晰度和可演奏性。

小测试

通过对和弦的听辨练习，进一步巩固对和弦的理解和识别能力。这个听辨更加考验听觉基本功，需要更长的时间来练习。
