音程与和弦（二）：度与音程

数键数

音程即是距离，数清楚键数才能准确判断音程。

相邻琴键相差一个半音，两个半音是一个全音。先在键盘上找到它们。

01

从 C 开始数

计算度数时包含首尾两个白键：例如C 到 E 是三度，C 到 G 是五度。点击下方任意音，先听 C，再听目标音，下方会显示它们的音程关系，感受一下不同音程听上去的差异。

选择一个目标音，查看它与 C 的关系。

02

听见大小与纯增减

二、三、六、七度通常有大和小；一、四、五、八度以“纯”为基础，再向上或向下变化为增、减。

半音是十二平均律中最小的音程单位，钢琴键上的每相邻的两个键之间相差一个半音。我们通常以半音计数，对应不同音高的音程差异。音程通常有旋律音程和和弦音程两种，两个音先后发声叫做旋律音程，同时发声叫做和弦音程。同一个音程在这两种模式下有不同的听感和应用，下面我们以C为基准音，来介绍不同音程。点击可以切换不同的模式。

二度

在和弦音程中，小二度间隔一个半音，听起来极度紧张且不和谐；大二度间隔2个半音，稍微明亮一些，但依旧不稳定；在旋律音程中，二者听起来都有一定的级进感和导向性。

三度

在和弦音程中，二者听上去都比较和谐。大三度相隔4个半音，听起来明亮、稳定；而小三度比大三度少一个半音，色彩更柔和、偏暗。在旋律音程中，二者有都有独特的小跳跃性。

四度

在和弦音程中，纯四度稳定，间隔5个半音，和谐但不那么饱满；而增四度间隔6个半音，带有更明显的不和谐感，有悬疑、紧张的感觉。在旋律音程中，四度听起来有一定的跳进感，且坚定、有力，通常有终止解决的性质。

五度

在和弦音程中，纯五度稳定，间隔7个半音；减五度（即增四度）带有不协和感，至于同一个音程什么时候用不同的名称，依情况而定。在旋律音程中，五度听起来形成了大跳进感。

六度

在和弦音程中，小六度（增五度）间隔8个半音，较柔和；大六度间隔9个半音，明亮，有稳重感。在旋律音程中，有较大的跨进感。

七度

在和弦音程中，小七度间隔10个半音，带有紧张感；大七度间隔11个半音，更为尖锐。在旋律音程中，七度通常形成更大的跳进感，具有强烈的导向性。

其中大二度和小二度就是我们所称的全音和半音，其中全音由两个半音组成。

依照上方的规律，你可以推算出各个基准音不同音程所对应的音高。现在再试试在音轨中写出这些双音吧！

点击下方的按钮，依次显示随机的基准音和音程，尝试着写出对应的音高吧！为了方便判定，长按拖拽放置长度为4格的音符！然后点击播放键，你的答案将由系统判定是否正确！

按下按钮开始八题音程练习。

03

把耳朵从键盘上带走

听觉推断不会总给你琴键。反复比较基准音与目标音，逐渐建立音程的听觉记忆。接下来是音乐素养中重要的一环————听觉训练。想要写出好的作品，你不仅要有能把旋律哼出来的能力，还要有把你哼出来的旋律写下来的能力。下面是两个较为简单的练习，你可以借助上方的音轨帮助建立你的听觉记忆。之后，再试着脱离标准音的辅助，独立判断音高和音程。
