音程与和弦（五）：简单和弦进行

让和弦向前走

和弦进行，让多个和弦按顺序连接起来。

和弦决定音乐的色彩，进行决定音乐如何产生方向感。先从四个和弦的循环开始。

01

什么是和弦进行

单独听一个和弦，可以感受到它的色彩；把几个和弦按顺序排列，就会产生出发、发展和回到稳定位置的感觉。和弦进行通常以罗马数字表示，数字代表和弦根音在调内的级数。

I：主和弦

常作为开始和结束，提供稳定的归属感。

V：属和弦

带有明显的回到 I 的倾向，制造期待。

vi：关系小和弦

与 I 共享多个音，适合带来柔和、抒情的变化。

02

三种常见进行

下面使用 C 大调试听三种入门和弦进行。点击卡片即可播放每个进行中的和弦顺序。你甚至可以把它们组合，放完一个后马上接上另一个，听听它们的感觉如何。

03

写进行时的三个步骤

先确定调

先选 C 大调这样的熟悉调性，确定可以使用的和弦。

再确定方向

用 I 作为落点，用 V 或 ii–V 制造回归感。

最后重复试听

循环播放，感受每次换和弦时的张力与释放。
