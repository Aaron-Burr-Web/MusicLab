音符与记谱

先听，再定位

声音有高低；音符帮你找到它，乐谱帮你把它留住。

1 每升高一个八度，听起来更亮；名称会从 C 再次开始。
01

音名与唱名

先记住这一圈：字母用于定位，唱名用于开口唱。

中央 C 到高音 C 带圆点的位置就是图片交互热点。
02

钢琴键盘

找 C 的最快方法：观察两颗黑键，左边紧邻的白键就是 C。

点击白键试听。黄色键标出两个 C，帮你快速建立坐标。

听音找键

先播放一个音，再选你听到的音名。

点击播放开始。
