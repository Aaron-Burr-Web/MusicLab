调式基础（五）：和弦色彩的转换与拼接

当基础和弦连接已经清晰之后，可以有意识地改变某一个音，或把两个调式的材料拼在一起。这样既能保留原来的方向感，也能让和声出现新的光泽。

01

同主音转换

保持主音不变，在大调与小调、Ionian 与 Dorian 等调式之间切换，是最容易听出色彩差异的方法。主音提供连续性，特征音负责改变情绪。

02

借用和弦

从同主音的平行调式中借来一个和弦，可以在不完全离开原调的情况下制造短暂的阴影或明亮变化。借用时要确认旋律是否能与这个新音共存。

03

拼接两个色彩段落

拼接时可以使用共同和弦、共同音或相同的节奏型作为接缝。先让前一段完成一个清楚的句子，再在下一段突出新的主音，听感会比突然更换一串和弦自然。

保留

保留主音、共同音或低音节奏，建立连续感。

改变

改变一个特征音或和弦质量，制造色彩转折。

回收

用新的终止或共同和弦确认下一段的归属。

04

一个可执行的练习

先写四小节 C 大调进行，再把其中两小节改成 C 小调或 C Dorian。保持节奏不变，只改变一到两个和弦音，反复试听色彩变化，再决定是否需要完整转调。
