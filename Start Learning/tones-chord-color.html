调式基础（五）：和弦色彩的转换与拼接

当你习惯了常规的和弦进行，你可能会面临一个困境。由于市面上的很多音乐的色彩会进行变化，当你第一次听到这些变化的时候，他可能会打破你的期待，给你带来不适的感觉，因为它脱离了原有进行规律，但往往这种变化正是音乐的魅力所在，它使得音乐有了给人耳目一新的感觉，并且增强了音乐的叙事性和自由性，丰富了他们的色彩。

01

同主音色彩转换

保持主音不变，在大调与小调、Ionian 与 Dorian 等调式之间切换，是最容易听出色彩差异的方法。主音提供连续性，这符合我们之前说的共同音原则，特征音负责改变情绪，所以在转变的过程中一般针对其特征音进行调整，或者是前后调式中突出而不同的音。从大转小，可以使情绪逐渐低落，从小转大，则会让情绪逐渐明亮，这样可以使音乐具有更多的叙事性。

02

借用和弦

从同主音的平行调式中借来一个和弦，可以在不完全离开原调的情况下制造短暂的阴影或明亮变化。借用时要确认旋律是否能与这个新音共存。

03

融合两种调式

拼接时可以使用共同和弦、共同音或相同的节奏型作为接缝。先让前一段完成一个清楚的句子，再在下一段突出新的主音，听感会比突然更换一串和弦自然。

保留

保留主音、共同音或低音节奏，建立连续感。

改变

改变一个特征音或和弦质量，制造色彩转折。

回收

用新的终止或共同和弦确认下一段的归属。

04

转调和桥接

歌曲中常见通过升调使情绪推向高潮，主要转变主音而没有调式切换，更多的音乐会在中间部分写一个bridge，部分遵循之前的规则，可以比较自由的写和弦连接，但不要破坏整体色彩，同时要注意前后段的衔接，使过渡自然。

一个可执行的练习

先写四小节 C 大调进行，再把其中两小节改成 C 小调或 C Dorian。保持节奏不变，只改变一到两个和弦音，反复试听色彩变化，再决定是否需要完整转调。
